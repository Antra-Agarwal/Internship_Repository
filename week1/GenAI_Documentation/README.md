# 📘 GenAI Documentation

## Overview

This folder contains concise documentation covering the fundamental concepts of the Generative AI ecosystem. The notes were prepared as part of **Week 1** of my Generative AI Internship to build a strong theoretical foundation before implementing real-world AI applications.

Each document explains a core concept using simple language, examples, diagrams, and key takeaways.

---

# 📂 Documentation Structure

| File                            | Description                                                                                                     |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **01_Generative_AI.md**         | Introduction to Generative AI, its features, applications, advantages, and limitations.                         |
| **02_Large_Language_Models.md** | Explains Large Language Models (LLMs), tokens, context window, temperature, and how LLMs generate responses.    |
| **03_Prompt_Engineering.md**    | Covers Prompt Engineering concepts, prompting techniques, and best practices.                                   |
| **04_RAG.md**                   | Introduces Retrieval-Augmented Generation (RAG), its workflow, advantages, and applications.                    |
| **05_Embeddings.md**            | Explains embeddings, semantic similarity, and their role in AI applications.                                    |
| **06_Vector_Databases.md**      | Describes vector databases, similarity search, and their importance in RAG systems.                             |
| **07_AI_Agents.md**             | Introduces AI Agents, their components, workflow, and real-world applications.                                  |
| **08_MCP.md**                   | Explains the Model Context Protocol (MCP), its architecture, and how it connects AI models with external tools. |
| **09_Real_World_Use_Cases.md**  | Highlights practical applications of Generative AI across different industries.                                 |
| **10_Conclusion.md**            | Summarizes the key concepts learned during Week 1 and outlines the overall understanding gained.                |

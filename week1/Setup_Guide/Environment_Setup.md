# Environment Setup

## Software Installation

Install the following software before starting the internship:

* Python 3.x
* Visual Studio Code
* Git
* Ollama (Optional)
* Google Chrome or another modern web browser

---

## Python Environment

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

### Windows

```bash
venv\Scripts\activate
```

---

## Upgrade pip

```bash
python -m pip install --upgrade pip
```

---

## Install Required Libraries

```bash
pip install langchain
pip install langgraph
pip install crewai
pip install python-dotenv
pip install langchain-google-genai
pip install openai
pip install ollama
```

---

## Verify Installation

```bash
python --version
git --version
pip list
```

If all commands execute successfully, the development environment is ready.

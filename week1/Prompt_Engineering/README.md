# Prompt Engineering Exercises

## Overview

This folder contains prompt engineering exercises completed as part of **Week 1** of my Generative AI Internship.

The objective of these exercises is to understand how different prompting techniques affect the quality, structure, and accuracy of responses generated by Large Language Models (LLMs).

## LLM Used

* Google Gemini
* Accessed through the Gemini web interface

## Topics Covered

* Simple Prompting
* Bad vs Good Prompt Comparison
* Role Prompting
* Structured Output
* Few-Shot Prompting
* Code Generation
* Creative Prompting

## Learning Outcome

Through these exercises, I learned how adding context, defining roles, specifying constraints, and requesting structured outputs significantly improves the quality of responses generated by an LLM.

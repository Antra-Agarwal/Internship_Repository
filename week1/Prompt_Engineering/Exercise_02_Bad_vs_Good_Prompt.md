# Exercise 2 – Bad vs Good Prompt

## Objective

To compare the responses generated by a vague prompt and a well-structured prompt, and understand how prompt quality affects the output of a Large Language Model (LLM).

---

## LLM Used

**Google Gemini (Web Version)**

---

# Part A – Bad Prompt

## Prompt

```text
Explain AI.
```

## Response Summary
``` text
The response provided a general explanation of Artificial Intelligence. It described AI, Machine Learning, Deep Learning, and Generative AI, along with common AI technologies such as Natural Language Processing, Computer Vision, and Speech Recognition. It also explained the difference between Artificial Narrow Intelligence (ANI) and Artificial General Intelligence (AGI).

Although the response was informative, it was quite lengthy and covered topics beyond the original request.
```

---

# Part B – Improved Prompt

## Prompt

```text
You are an AI professor.

Explain Artificial Intelligence to a second-year Computer Science student.

Requirements:

- Keep it under 300 words.
- Use simple language.
- Include one real-life example.
- Mention three real-world applications.
```

## Response Summary

The response explained Artificial Intelligence in a simple and structured manner suitable for a second-year Computer Science student. It used a real-life example of teaching a child to recognize a dog to explain how AI systems learn from data. It also highlighted three practical applications of AI:

1. Natural Language Processing (e.g., GitHub Copilot)
2. Computer Vision (e.g., Tesla Autopilot)
3. Advanced Robotics (e.g., Predictive Maintenance)

The explanation was concise, beginner-friendly, and followed all the specified requirements.

---

## Comparison

| Feature               | Bad Prompt                         | Improved Prompt                                     |
| --------------------- | ---------------------------------- | --------------------------------------------------- |
| Clarity               | General explanation                | Clearly focused on the target audience              |
| Structure             | Covered many unrelated topics      | Well-organized and easy to follow                   |
| Audience              | No specific audience               | Tailored for a second-year Computer Science student |
| Length                | Relatively long                    | Under 300 words as requested                        |
| Real-life Example     | Not included                       | Included a simple and relevant example              |
| Applications          | Discussed many concepts            | Mentioned exactly three applications as requested   |
| Instruction Following | No specific instructions to follow | Followed all instructions accurately                |

---

## Observation

* The vague prompt produced a broad, encyclopedia-style explanation.
* The improved prompt generated a response that matched the intended audience.
* Adding role, context, and constraints made the response more focused and easier to understand.
* The model followed the requested word limit and output structure.

---

## Key Learning

This exercise demonstrates that prompt quality has a direct impact on response quality. A well-designed prompt that specifies the role, audience, constraints, and expected output helps the LLM generate more relevant, structured, and useful responses than a vague prompt.

# Challenges and Learnings

## Overview

During Week 2, I built three AI-powered applications using Google Gemini and LangChain. This week provided practical experience in working with Large Language Models (LLMs), prompt engineering, and building modular Python applications.

While developing these projects, I encountered several challenges that helped me better understand Generative AI development.

---

# Challenges Faced

## 1. Learning LangChain

Initially, understanding the structure of LangChain components such as Chat Models, Prompt Templates, Output Parsers, and Chains was challenging. After building multiple applications, I became comfortable creating reusable AI pipelines.

---

## 2. Prompt Engineering

Writing effective prompts required experimentation. Small changes in wording often produced different responses, highlighting the importance of clear and specific instructions.

---

## 3. API Integration

Connecting applications to the Gemini API involved managing API keys securely using environment variables and understanding how to handle API responses and errors.

---

## 4. Error Handling

Building interactive applications required handling situations such as:

- Missing files
- Invalid user input
- Empty documents
- Unsupported file formats
- API rate limits

Adding proper exception handling made the applications more reliable.

---

## 5. File Processing

Implementing support for both text and PDF files required learning how to extract text from different file formats while maintaining a simple application structure.

---

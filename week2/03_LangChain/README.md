# LangChain Basics

## Overview

This module demonstrates the core concepts of LangChain using Google's Gemini model.

---

## Topics Covered

### 1. Chat Models
- Connecting LangChain with Gemini.
- Sending user messages.
- Receiving AI-generated responses.

### 2. Prompt Templates
- Creating reusable prompts.
- Replacing placeholders dynamically.

### 3. Output Parsers
- Converting model responses into plain strings.
- Preparing outputs for downstream processing.

### 4. Chains
- Connecting prompts, LLMs, and parsers into a single workflow.
- Building modular AI pipelines.

---

## Technologies Used

- Python
- LangChain
- Google Gemini
- python-dotenv

---

## Key Learnings

- LangChain simplifies LLM application development.
- Prompt Templates improve code reusability.
- Output Parsers provide cleaner outputs.
- Chains make AI workflows modular and easier to maintain.
